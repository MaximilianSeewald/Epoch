## Runtime fixes (separate from presentation)

- **Chapter 1:** SCAR still validates the native ship assignment, records completion and awards its original once-only research. Its report previously dispatched synchronously from the ship success callback. The new one-day `epoch_res.111` country dispatch leaves that callback stack before `epoch_res.11` evaluates country-keyed targets. Delivered/open report guards prevent repeated automatic delivery and concurrent windows. Funding/defer closes the window guard; capital recovery can reopen a deferred request. BASELINE still needs the player's paid choice (200 field / 500 archive Energy). No automatic project grant. The old game.log proves later selection, not initial delivery; the precise engine failure cannot be established retrospectively. The uninitialized-effects error is an additional plausible contributor.
- **Effect initialization:** the logged chain was repair -> infect -> site setter -> clear state -> clear contamination deposits. Expand the leaf cleanup directly, preserving its exact operation order and every caller guard. The complete scripted-effect graph now has maximum depth **3**, below the failing five-level limit. Expanded effect trees equal the baseline, including owner checks, all contamination deposits and planet flags. Scar/structure families remain independent.
- **Silent Structure:** the logged Vanilla completion of site 12 lacks a physical `planet`. The baseline already creates new sites inside `planet = { ... }`; no remaining direct Colony creation was found. New creation additionally requires a physical planet and excavation admission checks `site.planet`. The old retirement event required an active, unresolved inquiry and ownership of the old world: it could not retire completed or displaced legacy sites. Retirement now checks the campaign-keyed site identity/type and missing planet regardless of conclusion/world ownership. It destroys only that malformed site and its reference; completed results, features and rewards remain. Only unresolved active inquiries open the existing remote-study recovery. A global SP-load/monthly event and the country-yearly hook cover saves whose original situation has ended, including monthly MP coverage.
- **Save evidence limit:** the latest `autosave_2239.07.01.sav` still contains the saved site-12 target and several completed Silent Structures, with earlier excavation dates. That supports legacy persistence but cannot identify which build created the exact failing object. Logs establish the missing planet at completion, not the object's creation date. A fresh new-site and old-save runtime test remains necessary; no save file was modified.
- **Names:** keep country-keyed targets in scripts; snapshot local aliases in the actual country briefings. Localization uses `[epoch_res_battle_location.GetName]` / `[epoch_res_infected_world.GetName]`, following installed native `[battle_system.GetName]` / `[chosen_planet.GetName]`. The unsupported `event_target:` text promotion is removed. Scripted localization guards each alias and selects a natural fallback if absent.
