# Stage II Content Catalog

**Status: Binding scope catalog, not a claim of implementation.** Exactly five chapters are permitted. Individual content keys and mechanics are not approved until resolved in the next implementation design.

| Chapter | Required content | Valid result evidence |
|---|---|---|
| 1 – The Scar Wakes | Return signal; Stage I-dependent risks/findings/economics; Science Ship project or paid fallback | Completed research/paid action and durable report/record |
| 2 – The First Hunters | Actual hostile Nullwarden fleet in a visible system; victory, diversion, prepared defense, or withdrawal | Fleet/combat or alternative game-state result, persistent outcome |
| 3 – The Broken Code | Wreck/signal/archive analysis; real projects and science participation; research leads | Completed project and recorded lead; no free technology grant |
| 4 – The Second Infection | Planetary containment actions for quarantine, research, exploitation, failure | Distinct economy/stability/feature-state effect and recovery route |
| 5 – The Network of Silence | Multiple marked systems; real Science Ship projects; decisions informed by history | Distinct network findings and Stage III handoff record |

This catalog supersedes old eight-chapter content lists as active scope. Chamber activation, Countermark endings, and an in-Stage-II adapted Nullwarden finale are not Stage II deliverables; consult the migration matrix for the destination of each existing artifact.
